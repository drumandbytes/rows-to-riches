## Short description (≤ 150 characters)

An idle game about data engineering. Start with one CSV on localhost, end up cataloging the universe. Corporate satire included, free of charge.

## Description

You are the data team. You are also the only person on the data team. Your laptop is the server; please don't close the lid.

**Rows to Riches** is an incremental game about ingesting data. Click INSERT, hire Spreadsheet Interns, schedule Cron Jobs that email you every minute forever, and grow from a CSV on localhost to warehouses, lakehouses, orbital data centers and a Dyson Warehouse. Then the aliens arrive, and they have seven kinds of NULL.

**What's in it**

- 26 data sources, about 330 upgrades with synergies, and a schema whose columns multiply everything (the DBA has concerns).
- Four prestige layers, each with its own currency and upgrades: **Re-platform** (because a CTO read a blog post), **Acquisition** (employees get a hoodie), **First Contact** and the **Big Bang**. Then a final one, **Catalog Everything**, with New Game+.
- 22 challenges in tiers with fixed goals, a 1-hour limit and a speed bonus. They gate each prestige, so they aren't optional homework.
- Corporate life: quarterly OKRs graded at an all-hands, stakeholder requests that make you choose, meetings that could have been emails, and phishing tests you pass by *not* clicking.
- Incidents to click: PagerDuty alerts, backfills, viral dashboards, wormholes and the occasional abduction.
- 250+ achievements (some secret, and better found than read about), and Big Bang milestones up to 500.
- Ten number notations, from Finance deck (1.23 M) and Board memo (novemdecillion) to Legacy mainframe (Roman numerals) and Disk vendor (Gi). No number ceiling.
- Offline progress, a generative soundtrack per environment, and an installable app that plays offline.
- Optional cloud save with an account code: no email, no password, no tracking cookies, no ads.

Parody vendors include Sixtran, Snowfake, Databucks, Airbite, Lookie and Monty Carlo. Any resemblance to real vendors is, legally speaking, a vibe.
